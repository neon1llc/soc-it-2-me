# Reporting a problem

This is a knowledge resource, so a "vulnerability" here usually means **advice that is wrong, out of date or unsafe**. That matters as much as a bug in code, because people act on it.

- **Wrong or risky advice:** open an issue with the page link and what's wrong. If following the advice could hurt someone right now, mark the issue title `[urgent]`.
- **A problem with the site or tools** (for example a script injection in the built site): please report it privately through GitHub's "Report a vulnerability" button on this repository instead of a public issue.

You'll get a reply within a few days, and credit in the change log if you want it.
