---
title: The year-round calendar
description: "Every recurring control on one calendar, by month, so nothing slips during the observation window."
---

Shift the months to match your window. Put each item on a shared calendar with an owner and a backup, and create the ticket for it in advance.

| Month | Recurring work | Controls |
|---|---|---|
| 1 | Risk assessment, policy review and approval, quarterly access review, admin and secrets review, inventory refresh | RISK-01, RISK-02, GOV-03, ACC-03, ACC-05, ACC-06, RISK-03 |
| 2 | Yearly training and policy acknowledgments, vendor reviews for high-risk vendors | PPL-03, GOV-04, VEN-01, VEN-03 |
| 3 | Leadership program review, restore test | GOV-01, BCP-02 |
| 4 | Quarterly access review, admin and secrets review, inventory refresh | ACC-03, ACC-05, ACC-06, RISK-03 |
| 5 | Penetration test | VUL-02 |
| 6 | Tabletop exercise, continuity plan review, incident plan review | INC-03, BCP-03, INC-01 |
| 7 | Quarterly access review, admin and secrets review, inventory refresh | ACC-03, ACC-05, ACC-06, RISK-03 |
| 8 | Security owner role review, customer commitments review | GOV-02, GOV-05 |
| 9 | Leadership program review | GOV-01 |
| 10 | Quarterly access review, admin and secrets review, inventory refresh | ACC-03, ACC-05, ACC-06, RISK-03 |
| 11 | Independent review or readiness assessment, data classification review | RISK-04, DATA-01 |
| 12 | Evidence check: every instance for the year filed, auditor fieldwork if the window ends | All |

## Every event, all year

Access requests (ACC-01), departures (ACC-02), code changes (CHG-01, CHG-02, CHG-04), new hires (PPL-01, PPL-02, PPL-03, GOV-04), incidents (INC-02), lost and retired devices (END-02), new vendors (VEN-01, VEN-02), and deletion requests (DATA-02).
